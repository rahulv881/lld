## USER FLOW 

### FLOW 1. LOAD VENDING MACHINE INVENTORY
```
1. SELECT LOAD INVENTORY
2. TODO: AUTHORIZE INVENTORY LOADING 
   2.1 ASK PASSWORD
   2.2 GOTO STEP 3
   2.3 INVALID PASSWORD GOTO INITIAL STATE
3. SELECT ITEM AND GOTO STEP 4 OR QUIT AND GOTO INITIAL STATE
4. SELECT POSITION, VALIDATE IF POSITION IS EMPTY ELSE THROW ERROR
5. MARK ADDED GOTO STEP 3
```
### FLOW 2. PURCHASE ITEM
```
1. SELECT ITEM
2. START PAYMENT OF ITEM AMOUNT
3. IF PAYMENT IS DONE SUCCESFULLY, DESPENSE ITEM
4. ELSE NOTIFY USER PAYMENT FAILED WITH REASON
```
### FLOW 3. MAKE PAYMENT (OF ITEM AMOUNT)
```
1. INSERT MONEY WHILE (AMOUNT >= INSERTED MONEY) OR (PAYMENT CANCELLED BY USER)
2. RETURN EXCHANGE IF AMOUNT >= INSERTED MONEY
3. RETURN STATUS OF PAYMENT
```
### FLOW 4. MAINTAINANCE
```
1. NOTIFY USER: MACHINE IS UNDER MAINTAINANCE
2. START MAINTAINCE RELATED WORK
   2.1 DISABLE PRODUCT SELECTION
   2.2 DISABLE INVENTORY LOADING
   2.3 DISABLE PAYMENT
   2.4 DO OTHER MAINTANCE WORK E.G SECUTIRY UPDATE, PATCH UPDATE
3. WHEN MAINTAINANCE IS DONE
   3.1 ENABLE PRODUCT SELECTION
   3.2 ENABLE INVENTORY LOADING
   3.3 ENABLE PAYMENT
   3.4 SET MACHINE TO INITIAL STATE
```
